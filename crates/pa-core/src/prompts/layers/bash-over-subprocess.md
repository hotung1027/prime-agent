Never run shell commands through `subprocess`, `os.system`, or a helper that wraps them, even when you need the output. `r = await bash(cmd)` returns when the command finishes, with an integer `r.exit_code` and `r.output`. A handle left running (`h = bash(cmd)` without awaiting it in this cell) keeps running; `r = await h` in a later cell returns when that command finishes.
